# Changelog

All notable changes to ROOT Language Support will be documented in this file.

This project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-16

### Added
- Initial release of ROOT Language Support.
- Registered `.root` file extension.
- Added TextMate grammar for syntax highlighting.
- Added keyword highlighting.
- Added primitive type highlighting.
- Added string and character literal highlighting.
- Added numeric literal highlighting.
- Added line and block comment highlighting.
- Added operator highlighting.
- Added bracket matching and automatic indentation.
- Added basic language configuration for ROOT files.

### Notes
- This release provides basic editor support only.
- No compiler, debugger, or Language Server Protocol integration is included.
